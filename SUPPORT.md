# Destek

SEOAutoPilot topluluk tarafından geliştirilen bir MVP'dir; ücretli destek veya çalışma
süresi garantisi sunmaz.

- Hata: GitHub'da **Bug report** şablonunu kullanın.
- Özellik fikri: **Feature request** şablonunu kullanın.
- Güvenlik açığı: herkese açık issue açmayın; `docs/SECURITY.md` yolunu izleyin.

Bildirimlere gizli anahtar, token, Search Console dışa aktarımı veya kişisel klasör yolu
eklemeyin. Desteklenen ortam Node.js 22+ ve öncelikli olarak Windows 10/11'dir.
